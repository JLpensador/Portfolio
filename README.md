## 📌 Como Executar Localmente


1️⃣ Clone este repositório:

```bash
git clone https://github.com/JLpensador/Portfolio.git
```

2️⃣ Instale as dependências:

```bash
cd Portfolio
npm install
```

3️⃣ Rode em modo de desenvolvimento:

```bash
ng serve
```

4️⃣ Acesse no navegador: http://localhost:4200
